## 🛠 Project Overview
AgriSaudi bridges critical policy and governance gaps in agricultural tech deployment in Saudi Arabia by aligning standard crop disease detection with the ITU-T Y.3172 framework and national Saudi regulations (SDAIA, PDPL, NDMO, MEWA, GEOSA, CST).
